# Segment Anything Model 2 (SAM 2) - Meta AI

## Descripción General
**SAM 2 (Segment Anything Model 2)** es un modelo fundacional de visión por computadora de última generación desarrollado por Meta AI (FAIR) para la segmentación unificada e interactiva de objetos en imágenes y videos (*promptable visual segmentation*). Basado en una arquitectura *Transformer* de transmisión (*streaming*) dotada de un módulo de memoria en tiempo real, el modelo procesa fotogramas de forma secuencial y permite segmentar y rastrear cualquier objeto a partir de indicaciones visuales simples (clics positivos/negativos, cajas delimitadoras o máscaras iniciales). En el contexto de este proyecto, SAM 2 se implementa para la extracción, delimitación y análisis automatizado de elementos visuales y geoespaciales con capacidad de generalización *zero-shot*.
